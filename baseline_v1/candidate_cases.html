Python case discussions

The interviewer will select one case and introduce additional information during the discussion. Explain your assumptions, sketch an implementation, and write or direct a short piece of Python when asked. A complete production system or fitted forecasting model is not required.

Case one Replacement sales process

You are designing a Python process to forecast monthly replacement sales for the next 12 months. Two files contain historical bullet sales and handgun sales. Bullet sales have two channels: TF, sold together with firearms, and RS, replacements. The requested outputs are replacement sales by bullet type and by handgun maker and model. Explain the data checks and transformations you would implement, sketch the process, and write one small transformation with tests. You do not need to fit a forecasting model during this interview. State any output you cannot support from the supplied information.

FileColumns
bullets_sales.csvDate, Maker, Model, Bullets, Channel, Quantity
handgun_sales.csvDate, Maker, Model, Quantity

Questions to consider

  • What do you need to clarify about the output and the source data?
  • What checks and transformations would you implement?
  • What can you deliver from the available information?
  • How would you test the process and evaluate a future forecast?

Case four Faster historical features

A feature job computes the mean of earlier values from the same entity in the interval [minute - 3, minute). It requires at least two earlier observations. Keys (entity, minute) are unique and input order is arbitrary. The current implementation scans the complete table for each row. Explain its cost, design a faster implementation, and show how you would prove the result is unchanged. Do not replace a time interval with a fixed number of rows.

def slow_features(rows):
    result = []
    for row in rows:
        history = [
            r["value"] for r in rows
            if r["entity"] == row["entity"]
            and row["minute"] - 3 <= r["minute"] < row["minute"]
        ]
        result.append(
            sum(history) / len(history)
            if len(history) >= 2 else None
        )
    return result

Work out the result for the example, propose a faster approach, and explain how you would compare the two implementations.
